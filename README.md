# Nykaa Luxury Beauty Sales & Performance Dashboard

## Project Overview

An interactive Power BI dashboard designed to analyze luxury beauty sales performance using a synthetic dataset inspired by Nykaa's product and retail business. The project focuses on transforming raw data into meaningful business insights through data cleaning, data modeling, DAX calculations, and interactive visualizations.

The dashboard provides insights into sales trends, product category performance, top-performing brands, sales channels, and profitability through a clean, premium-inspired interface.

## Objectives

* Analyze monthly sales trends and overall revenue performance.
* Identify high-performing product categories and luxury brands.
* Compare sales performance across different sales channels.
* Evaluate gross profit and profitability by category.
* Build an interactive dashboard with dynamic filters and bookmark-based navigation.
* Present business insights through a visually appealing and user-friendly interface.

## Tools & Technologies

* **Power BI** – Dashboard development and data visualization
* **Power Query** – Data cleaning, transformation, and preparation
* **DAX** – Measures, calculated columns, and time intelligence
* **Microsoft Excel** – Dataset storage and source data management

## Data Preparation

The synthetic dataset was designed to simulate luxury beauty sales transactions from 2023 to 2026. Data preparation in Power Query included:

* Removing duplicate records
* Correcting data types
* Trimming and cleaning text fields
* Standardizing inconsistent categorical values
* Identifying and handling invalid discount percentages, customer ratings, and inventory values
* Preparing the dataset for analysis

## Data Modeling & DAX

A dedicated Date table was created and connected to the Sales table through a date relationship to support time-based analysis.

Key DAX measures included:

* Total Net Sales
* Total Orders
* Total Units Sold
* Total Customers
* Total Gross Profit
* Gross Margin %
* Average Order Value
* Return Rate %
* Average Discount %
* Previous Year Sales
* Year-over-Year Sales Growth %
* Sales per Customer

## Dashboard Features

The dashboard includes:

* **Monthly Sales Trend** – Tracks sales performance over time.
* **Sales by Category** – Compares revenue across product categories.
* **Top 10 Brands** – Highlights leading brands based on net sales.
* **Sales by Channel** – Compares sales across website, app, and retail channels.
* **Gross Profit by Category** – Evaluates category-level profitability.
* **KPI Summary** – Displays key business performance indicators.
* **Interactive Filter Navigation** – Uses buttons, bookmarks, and slicers to filter the report by year, category, brand, city, channel, and luxury tier.
* **Clear Filters** – Allows users to return to the default dashboard view.

## Dataset Disclaimer

This project uses a **synthetic dataset created for learning and portfolio demonstration purposes**. It does not contain actual Nykaa transaction records, confidential company data, or verified business performance figures. The insights are illustrative and should not be interpreted as official Nykaa results.
